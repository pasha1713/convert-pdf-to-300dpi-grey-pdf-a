# PDF → PDF/A-2b конвейер

Пакетная конвертация PDF в архивный формат **PDF/A-2b** (300 dpi) через
Ghostscript, постобработка `pikepdf`, валидация через **veraPDF**.

Проверено на:
- Ghostscript 10.08.0 (Windows)
- pikepdf 9.x
- veraPDF 1.30 (GreenField)
- Poppler (`pdfimages`, `pdftotext`)
- Windows 10/11, Python 3.10+

## Зачем это нужно

Формат PDF/A — стандарт ISO 19005 для долгосрочного архивного хранения
документов. Он требует:

- все шрифты **встроены**;
- описан **OutputIntent** + ICC-профиль;
- метаданные XMP явно указывают версию PDF/A;
- запрещены шифрование, внешние ссылки, JavaScript.

Росреестр и другие госорганы принимают документы в PDF/A-2b. Этот проект —
готовый конвейер, который:

1. Прогоняет каждый PDF через Ghostscript и делает PDF/A-2b.
2. Дополнительно чистит артефакты GS (XMP, CIDSet, EOL у stream, post/maxp).
3. **Обесцвечивает** content streams (rg/RG/k/K → g/G), если не отключено.
4. Для отдельных файлов может **сохранить цвет** (`KEEP_COLOR_PREFIXES`).
5. Валидирует результат через veraPDF + проверяет dpi/grayscale.
6. Опционально накладывает OCR-слой поверх растров.
